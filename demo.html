Prism Pride Highlighter

Lesbian, gay, bisexual, transgender, nonbinary, queer, asexual, pansexual, intersex, and genderfluid are highlighted using their associated colours.

Try the 48×48 prism button in the lower corner. It opens the same settings dock used on normal websites: protection, site exclusion, style, intensity, labels, accessibility, performance, and the searchable identity list.

This page loads pride-flag-highlighter.user.js directly, so the demo always exercises the current implementation instead of a copied version.
