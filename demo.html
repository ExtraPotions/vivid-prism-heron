Pride Flag Highlighter — local demo

Open this file in a browser. Identity words below should render with pride-flag gradient text (no Tampermonkey required — the highlight engine is inlined). Dark/light backgrounds both work.

Rainbow & inclusive pride

Words like queer, LGBT, LGBTQ, LGBTQ+, LGBTQIA+, and pride use the classic rainbow. Progress pride and Philadelphia pride / more color more pride / Philly pride / inclusive pride are also matched.

Ignored contexts

Inside code, words like gay and trans should stay plain:

const labels = ['gay', 'trans', 'ace', 'enby'];

Content-editable also stays plain: edit me: bisexual pansexual nonbinary
